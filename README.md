# C++ Homework

My solutions to the homework and tests from an introductory C++ programming course. Each folder contains the task statement (PDF, in Bulgarian) and one `.cpp` file per task.

| Folder | Contents |
|---|---|
| [`Homework 1`](Informatics/Homework%201) | Conditions and expressions |
| [`Homework 2`](Informatics/Homework%202) | Functions, arrays and geometry |
| [`Homework 3`](Informatics/Homework%203) | Dynamic memory (arrays allocated with `new`) |
| [`Control 1`](Informatics/Control%201) | Test 1 (variants 1 and 2) |
| [`Control 2`](Informatics/Control%202) | Test 2 |

## Running a solution

```bash
g++ "Informatics/Homework 1/task1.cpp" -o task1
./task1
```

Need a compiler? See my [VS Code + GCC setup guide](https://github.com/alifrommars/Installation-of-VSCode).
